# Strix Developer Documentation

A shared technical reference for building, integrating, deploying, and maintaining software systems at Strix Engineering Studio.

## Documentation areas

- **Getting started:** onboarding, tools, local setup, and development environments.
- **Engineering:** architecture, coding standards, testing, and security.
- **Operations:** CI/CD, deployment, observability, and troubleshooting.
- **Products:** implementation details and integrations for individual Strix products.

## Documentation principles

1. Make instructions reproducible.
2. State prerequisites and supported versions.
3. Prefer complete examples over fragments.
4. Explain failure modes and recovery steps.
5. Keep secrets and customer-confidential information out of this repository.
