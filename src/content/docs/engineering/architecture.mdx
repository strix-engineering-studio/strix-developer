# Architecture

## Design expectations

- Define system boundaries and ownership.
- Separate domain logic from frameworks and infrastructure.
- Document data ownership, integration contracts, and trust boundaries.
- Make critical failure modes explicit.
- Prefer observable, testable, and replaceable components.

## Architecture decision records

For significant decisions, document context, options, selected approach, trade-offs, consequences, and revisit conditions. Keep records close to the project they govern.
