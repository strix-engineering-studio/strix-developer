# Developer onboarding

## Before you start

Obtain access to the relevant GitHub repositories, task tracker, communication channels, and development environments from the project owner.

## Onboarding sequence

1. Read the project README and architecture overview.
2. Confirm supported runtime and package manager versions.
3. Configure local environment variables using the project's example file.
4. Install dependencies and run the application.
5. Run tests, linting, and type checks.
6. Review deployment and release procedures before changing production-sensitive systems.

## Access and security

Use individual accounts and least-privilege access. Never share tokens or commit credentials. Request access through the approved owner-managed process.
