# Code standards

- Follow the language and framework conventions adopted by the project.
- Run formatting, linting, static analysis, and relevant tests before review.
- Use descriptive names and keep functions focused.
- Validate inputs at system boundaries.
- Handle errors explicitly and preserve useful diagnostic context.
- Avoid secrets, sensitive data, and unnecessary logging of personal information.
- Prefer small, reviewable pull requests with clear descriptions and test evidence.
