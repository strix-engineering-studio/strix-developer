# Troubleshooting

1. Capture the exact error, timestamp, environment, and affected operation.
2. Determine scope and user impact.
3. Check recent deployments, configuration changes, dependencies, and service health.
4. Reproduce safely without exposing customer data or credentials.
5. Apply the smallest reversible mitigation.
6. Verify recovery and document root cause and follow-up actions.

Do not paste access tokens, passwords, private keys, or sensitive user records into issues or documentation.
