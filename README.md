# Strix Developer Documentation

The technical documentation hub for Strix Engineering Studio projects, platforms, reusable systems, and integrations.

## Scope
- Developer onboarding and local setup
- Architecture and technical standards
- API, SDK, and integration references
- Deployment, CI/CD, observability, and operations
- Troubleshooting and runbooks

## Stack
- Astro + Starlight
- Markdown and MDX
- Custom Astro components
- GitHub Pages via GitHub Actions

## Local development
```bash
npm install
npm run dev
```

Push to `main` to trigger the Pages deployment workflow. Configure repository Settings → Pages to use GitHub Actions. Never commit secrets or confidential customer information.
